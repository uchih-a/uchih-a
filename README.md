## 🧠 Selected Projects

---

### 🤟 SignSense — ASL Recognition Progressive Web App

**Problem:** Most sign language systems recognize isolated gestures and fail in real-world use.

**What I built:**
- Real-time letter (A–Z) + word (30-frame sequence) recognition using MediaPipe + TensorFlow/Keras
- Full-stack PWA with JWT auth, role-based access control (admin/user), and inference history logging
- Async FastAPI backend + PostgreSQL + React + TypeScript frontend

**Stack:** `Python` `FastAPI` `TensorFlow/Keras` `MediaPipe` `React` `TypeScript` `PostgreSQL` `Docker`

[View Repository →](https://github.com/uchih-a/Voxign)

---

### 🌍 LandIQ — AI Land Valuation for Kenya

**Problem:** Land valuation in Kenya lacks transparent, data-driven systems.

**What I built:**
- MLP neural network trained on 5,796+ real listings across 30 counties (71% R² accuracy)
- Interactive geospatial maps with county-level investment rankings
- Full-stack: FastAPI backend + React/TypeScript frontend + PostgreSQL + MapLibre GL
- Deployed live at [landiq-one.vercel.app](https://landiq-one.vercel.app)

**Stack:** `Python` `PyTorch` `FastAPI` `React` `TypeScript` `PostgreSQL` `MapLibre GL` `Docker`

[View Repository →](https://github.com/uchih-a/landiq) · [Live Demo →](https://landiq-one.vercel.app)

---

### 🌾 AgriYield Kenya — Crop Yield Prediction System

**Problem:** Kenyan farmers lack predictive tools for crop planning across diverse agro-ecological zones.

**What I built:**
- Bidirectional LSTM trained on 30,492 records (2016–2024) across 7 agro-ecological regions
- Streamlit web app with authentication, yield predictions, trend charts, and PDF report export
- Full interactive dashboard: rainfall vs yield scatter, regional yield comparisons, soil pH analysis

**Stack:** `Python` `TensorFlow/Keras` `Scikit-learn` `Streamlit` `Plotly` `Supabase`

[View Repository →](https://github.com/uchih-a/kenya_crop_yield_prediction)

---

### 🌿 AgroVet (Stockify) — Agricultural Inventory & AI Platform

**Problem:** Kenyan agrovet businesses lack digital tools to manage inventory, sales, and farmer relationships.

**What I built:**
- Full-stack inventory management platform for agrovet shop owners and farmers
- AI chatbot (Google Gemini) for real-time agricultural guidance
- Stripe payments, stock alerts via email (Nodemailer), Cloudinary image storage
- Role-based access: admin dashboard + farmer marketplace
- Deployed at [stockify-agrovet.vercel.app](https://stockify-agrovet.vercel.app)

**Stack:** `React` `Node.js` `Express` `MongoDB` `Google Gemini` `Stripe` `Cloudinary` `JWT`

[View Repository →](https://github.com/uchih-a/Stockify-Agrovet) · [Live Demo →](https://stockify-agrovet.vercel.app)
